# Product Requirements Document

## Vision
Автоматический бот для игры Dwar.ru, который добывает ресурсы, защищается от монстров, управляет здоровьем персонажа и оповещает игрока о критических событиях (капча, низкое здоровье). Бот работает как автономный клиент для браузерной версии игры.

## Target Users
- **Игроки Dwar.ru**, которые хотят автоматизировать рутинные действия (сбор ресурсов, прокачка профессий)
- **Фармеры ресурсов**, которым нужен стабильный сбор материалов 24/7
- **Разработчики**, желающие изучить автоматизацию браузерных игр на TypeScript

### Pain Points
- Однообразный крафт/сбор ресурсов отнимает много времени
- Нужно постоянно следить за атаками монстров
- Капча прерывает автоматизацию и требует ручного вмешательства
- Персонаж может умереть при AFK из-за атак

## Success Metrics
- **Uptime**: бот работает > 90% времени без падений
- **Farming Rate**: сбор > 100 ресурсов/час
- **Survival Rate**: < 1 смерти в день от монстров
- **Captcha Response Time**: игрок решает капчу < 60 секунд после звукового сигнала

## Constraints
- **Технические**: браузерная игра, доступ только через DOM (нет API)
- **Правовые**: проект для обучения, использование на свой риск
- **Производительность**: один инстанс бота = один аккаунт = один браузерный процесс
- **Команда**: соло-разработчик

## Non-Goals
- ❌ Имитация "человеческого" поведения (рандомные паузы, органическое движение мыши)
- ❌ PvP автобои с другими игроками
- ❌ Взлом игрового клиента или модификация памяти
- ❌ Обход серверной защиты от ботов (кроме решения капчи)
- ❌ Коммерческое распространение или продажа
